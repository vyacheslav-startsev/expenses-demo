# Учёт расходов

Небольшое веб-приложение для учёта личных расходов: FastAPI, SQLite и шаблоны Jinja2.
Расход вводится руками (сумма, дата, категория, комментарий), наверху страницы итог
месяца и диаграмма по категориям, между месяцами можно листать стрелками.

## Запуск

```bash
uv sync
uv run python seed.py      # расходы за октябрь и начало ноября 2026
uv run uvicorn app.main:app --reload
```

Приложение откроется на http://127.0.0.1:8000. База лежит в `expenses.db`, другой
путь задаётся переменной `EXPENSES_DB`.

## Тесты

```bash
uv run pytest
```

## Импорт выписки

Расходы по карте не обязательно вбивать руками: на главной есть блок «Загрузить выписку».
После загрузки CSV открывается экран проверки: что будет добавлено и с какой категорией,
что пропущено и почему (неуспешные операции, зачисления, не рубли, уже загруженное).
Категорию можно поменять, лишнее снять галочкой; переводы по умолчанию не отмечены.
Повторная загрузка той же выписки ничего не задваивает.

Формат: UTF-8, разделитель `;`, суммы с запятой, расходы со знаком минус. Пример —
`samples/statement-2026-11.csv`, выписка по карте за 1–11 ноября 2026, данные выдуманы.
Учтите, что `seed.py` уже содержит часть этих покупок, введённых руками, поэтому на
демо-базе после импорта 1–6 ноября они задвоятся.
