# Учёт расходов

Небольшое веб-приложение для учёта личных расходов: FastAPI, SQLite и шаблоны Jinja2.
Расход вводится руками (сумма, дата, категория, комментарий), наверху страницы итог
месяца и диаграмма по категориям, между месяцами можно листать стрелками.

## Запуск

```bash
uv sync
uv run python seed.py      # расходы за октябрь и начало ноября 2026
uv run uvicorn app.main:app --reload
```

Приложение откроется на http://127.0.0.1:8000. База лежит в `expenses.db`, другой
путь задаётся переменной `EXPENSES_DB`.

## Тесты

```bash
uv run pytest
```

## Выписка для импорта

В `samples/statement-2026-11.csv` лежит выписка по карте за 1–11 ноября 2026 в формате,
похожем на банковский: разделитель `;`, суммы с запятой, расходы со знаком минус.
Все данные выдуманы.
